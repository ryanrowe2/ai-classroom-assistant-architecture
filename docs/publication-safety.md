## Automated packaging rules

The repository checker deliberately permits only human-readable `.md`, `.json`, `.py`, `.svg` and `.dot` artifacts. It rejects large or binary files and scans for high-confidence private keys, API credentials, email addresses and characteristic long passages from source documents. The public package does not redistribute the original PRD, the six-week timeline, employee communications, application source code, infrastructure secrets or genuine customer/student records.

An allowlist and pattern scanner can miss renamed or paraphrased confidential material; passing scans is **not** a confidentiality certification. Check every new file and diagram manually for internal information, project-specific infrastructure, team identities, client relationships, third-party licensed media and sensitive educational data. All synthetic strings and names here are fabricated for acceptance-test design.
